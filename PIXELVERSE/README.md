# 🎮 PixelVerse – Gaming Universe

> An interactive multi-game arcade universe designed to provide a fun, engaging and visually attractive gaming experience.

## 🌟 Project Overview

PixelVerse Gaming Universe is a graphical-based gaming platform that brings multiple mini-games together in one interactive arcade environment.

The project focuses on creating an attractive gaming experience with a centralized dashboard, interactive gameplay, rewards and player progression.

## 🕹️ Games Included

### 🐍 Snake Rush
Classic snake gameplay where the player controls the snake, collects items and tries to achieve a high score.

### 🧠 Memory Master
A memory-based game designed to test and improve the player's memory and concentration.

### 🚀 Space Blast
An interactive space-themed game where players experience an arcade-style challenge.

### ❌⭕ Tic Tac Toe
A classic Tic Tac Toe game with an interactive graphical interface.

## ✨ Key Features

- 🎮 Multiple games in one platform
- 🖥️ Interactive gaming dashboard
- 🎨 Attractive arcade-style UI
- 🏆 Score-based gameplay
- 🔥 Player progression and streak concepts
- ⭐ Reward-oriented gaming experience
- ⚡ Fast and interactive gameplay
- 📱 User-friendly interface
