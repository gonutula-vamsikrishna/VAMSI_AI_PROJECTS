## 📂 My Projects

### 🎮 PixelVerse – Gaming Universe

An interactive multi-game arcade platform designed to provide an engaging and visually attractive gaming experience.

PixelVerse brings multiple mini-games together through a centralized gaming environment with interactive gameplay, scores, rewards, and player progression.

**Technologies:** Python, Flask, HTML5, CSS3, JavaScript

👉 [View PixelVerse](./PIXELVERSE)

### 💧 AquaSearch – DLS Water Tank Simulation

A web-based Dynamic Logic System (DLS) water tank simulation that demonstrates how water levels can dynamically increase or decrease according to predefined logic.

The project provides a visual representation of dynamic water-level control using an interactive interface.

**Technologies:** Python, Flask, HTML5, CSS3, JavaScript

👉 [View AquaSearch](./AquaSearch)
