# 💧 AquaSearch – Dynamic Logic System Water Tank

## 📌 Project Overview

AquaSearch is a web-based Water Tank Simulation developed using the concept of Dynamic Logic System (DLS).

The project demonstrates how the water level in a tank can be dynamically controlled based on different water-level conditions. When the water level changes, the system responds accordingly and increases or decreases the water level based on the defined logic.

This project connects a real-world water tank problem with programming and web development concepts.

## 🎯 Objective

The main objective of this project is to demonstrate the practical application of Dynamic Logic System using a simple and understandable Water Tank example.

## ⚙️ How It Works

The system monitors the water level of the tank.

- When the water level is low, the system increases the water level.
- When the water level reaches a higher level, the system controls the water flow.
- The water level is dynamically represented on the web page.
- The system responds according to the predefined logic.

## ✨ Features

- 💧 Dynamic water tank visualization
- 📊 Water level monitoring
- 🔄 Dynamic increase and decrease of water level
- ⚙️ Logic-based water level control
- 🌐 Interactive web interface
- 🎨 Attractive user interface
