# 💧 AquaSearch – Dynamic Logic System Water Tank

> A web-based water tank simulation demonstrating the concept of Dynamic Logic System (DLS) through an interactive and visual interface.

---

## 📌 Project Overview

AquaSearch is a web-based Water Tank Simulation developed using the concept of **Dynamic Logic System (DLS)**.

The project demonstrates how a water tank can dynamically respond to different water-level conditions. Based on the defined logic, the system visually represents the increase or decrease of the water level.

The main goal of this project is to make the concept of Dynamic Logic System easier to understand through a practical and interactive simulation.

---

## 🌊 Key Features

- 💧 Dynamic water-level simulation
- 📈 Water level increase and decrease
- 🧠 Dynamic Logic System implementation
- 🎨 Interactive graphical interface
- ⚡ Real-time visual response
- 🖥️ User-friendly web interface
- 📊 Visual representation of different water levels

---
